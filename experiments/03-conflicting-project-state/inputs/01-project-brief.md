# Project Brief

Last updated: October 1, 2026

Project: Lantern

Lantern is a small internal web application scheduled for release on November 10, 2026.

Current technical plan:

- Authentication: Auth0
- Production database: PostgreSQL
- Hosting: Vercel
- Observability provider: not yet selected

The team wants to keep the first release simple and avoid changing the database architecture unless there is a clear reason to do so.
